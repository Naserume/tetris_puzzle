# Tetris Puzzle

브라우저에서 돌아가는 테트리스와 테트리스 퍼즐. 빌드 도구 없이 정적 파일만으로
동작합니다.

페이지는 셋입니다.

| 페이지 | 내용 |
| --- | --- |
| `index.html` | 메인 화면. 마라톤 / 레슨 / 복습 / 랜덤 퍼즐 선택과 문제 목록 |
| `play.html` | 원본 테트리스. 중력이 있고 되돌릴 수 없습니다 |
| `puzzle.html` | 퍼즐 플레이어. 중력이 없고 되돌릴 수 있습니다 |

## 실행

ES 모듈을 쓰기 때문에 `index.html` 을 직접 더블클릭하면 브라우저가 모듈 로딩을
막습니다. 로컬 서버를 하나 띄우세요.

```sh
python3 -m http.server 8765
# http://localhost:8765
```

## 조작

기본값입니다. 우측 상단 ⚙ 버튼에서 전부 바꿀 수 있습니다.

| 키 | 동작 |
| --- | --- |
| `←` `→` | 이동 |
| `↓` | 소프트 드롭 |
| `Space` | 하드 드롭 |
| `↑` / `X` | 시계 방향 회전 |
| `Z` / `Ctrl` | 반시계 방향 회전 |
| `A` | 180° 회전 |
| `C` / `Shift` | 홀드 |
| `P` / `Esc` | 일시정지 |
| `R` | 다시 시작 |

터치 기기에서는 화면 하단 버튼으로 조작합니다.

## 설정

⚙ 버튼을 누르면 설정 창이 열립니다. 창을 여는 동안 게임은 자동으로 멈춥니다.

- **조작키**: 키를 클릭한 뒤 원하는 키를 누르면 지정됩니다. 한 동작에 최대 3개까지
  묶을 수 있고, 이미 다른 동작이 쓰던 키를 지정하면 그쪽에서 자동으로 떼어옵니다.
  `×` 로 개별 해제, 취소는 아무 곳이나 클릭. Esc 를 포함해 모든 키를 지정할 수 있습니다.
- **DAS**: 좌우 키를 누른 뒤 자동 이동이 걸리기까지의 시간 (기본 133ms)
- **ARR**: 자동 이동 중 한 칸당 간격 (기본 20ms, 0 이면 벽까지 한 번에)
- **소프트 드롭**: 아래 키를 누르고 있을 때 한 칸당 간격 (기본 25ms, 0 이면 바닥까지 한 번에)

설정은 localStorage 에 저장되어 다음 접속에도 유지됩니다. 저장이 막힌 환경
(시크릿 창 등) 에서는 기본값으로 돌아갈 뿐 동작에는 지장이 없습니다.

## 구현된 규칙

가이드라인 테트리스를 따릅니다.

- SRS 회전과 월킥 (I 피스 전용 테이블 포함)
- 7-bag 랜덤: 7개마다 각 블록이 정확히 한 번씩
- 홀드 (블록당 1회), 고스트 피스, 다음 블록 5개 미리보기
- 락 딜레이 500ms, 이동/회전으로 최대 15회까지 리셋
- T-스핀 판정 (3-코너 규칙, mini / full 구분)
- 점수: 싱글 100 / 더블 300 / 트리플 500 / 테트리스 800 × 레벨,
  백투백 ×1.5, 콤보 50 × 콤보수 × 레벨, 소프트 드롭 1칸당 1점, 하드 드롭 2점
- 10줄마다 레벨 상승, 레벨에 따른 중력 가속

## 퍼즐

퍼즐은 원본을 건드리지 않고 **같은 엔진에 옵션만 다르게 준 것**입니다.
`new Game({ grid, queue, gravity: false })` — 미리 깔린 보드, 정해진 가방,
그리고 꺼진 중력. 원본은 옵션 없이 그대로 돌아갑니다.

### 세 가지 모드

- **레슨** — 아직 못 푼 문제부터 순서대로
- **복습** — 풀어본 문제 중 미해결부터, 그다음은 오래된 순서로
- **랜덤 퍼즐** — 전체에서 무작위 한 문제

### 두 가지 채점 방식

- **한 수씩**(`guided`) — 조각을 놓는 즉시 판정합니다. 맞으면 ✓ 와 설명,
  틀리면 ✗ 와 이유를 말풍선으로 띄우고 1초 뒤 스스로 되돌립니다. 되돌아가면
  같은 조각이 그대로 손에 돌아오므로 막히는 일이 없습니다.
- **끝까지 두고 채점**(`free`) — 중간에는 아무 말도 하지 않습니다. 가방이
  비면 그때 목표 달성 여부로 한 번에 채점합니다.

### 되돌리기

수는 전부 기록됩니다. 한 수씩 되돌리거나(`Backspace` / `U`) 처음으로
돌아갈 수 있고(`R`), 틀린 수는 위처럼 저절로 되돌아갑니다. 되돌리기는 조각이
나올 때마다 찍어 둔 전체 스냅샷을 복원하는 방식입니다 — 줄이 지워진 뒤에는
역연산이 지저분해지기 때문입니다.

### n번째 문제 불러오기

```
puzzle.html?n=4          네 번째 문제
puzzle.html?id=lesson-tspin
puzzle.html?mode=lesson  아직 못 푼 첫 레슨부터
puzzle.html?mode=review
puzzle.html?mode=random
```

### 문제 추가하기

`js/puzzles.js` 에 객체 하나를 더하면 끝입니다. 보드는 아래쪽 줄만 문자열로
쓰면 위는 자동으로 채워집니다.

```js
{
  id: 'lesson-line',
  kind: 'lesson',          // lesson | puzzle
  mode: 'guided',          // guided | free
  title: '첫 줄 지우기',
  brief: '무엇을 해야 하는지 한 줄',
  board: ['....XXXXXX'],   // '.' 빈 칸, 그 외는 채워진 칸
  queue: ['I'],            // 이 문제의 가방
  steps: [{ cells: [[0,19],[1,19],[2,19],[3,19]], note: '맞았을 때 띄울 말' }],
  defaultWrong: '틀렸을 때 띄울 말',
  hint: '힌트 버튼을 눌렀을 때',
}
```

판정은 회전 상태가 아니라 **덮은 칸의 집합**으로 합니다. S·Z·I는 회전 상태가
달라도 같은 칸을 덮을 수 있고, 같은 칸을 덮었다면 같은 수이기 때문입니다.
`ordered: false` 를 주면 여러 수를 아무 순서로나 받습니다. `note` 가 없으면
말풍선은 뜨지 않고 ✓/✗ 표시만 남습니다.

진행 상황은 localStorage 에 저장되며, 메인 화면의 "진행 기록 지우기" 로
초기화할 수 있습니다.

## 구조

```
index.html              메인 화면
play.html               원본 테트리스
puzzle.html             퍼즐 플레이어
style.css               스타일
js/pieces.js            블록 모양과 SRS 킥 테이블
js/engine.js            게임 규칙 (DOM 비의존 — 원본·퍼즐·테스트가 공유)
js/render.js            캔버스 렌더링, ✓/✗ 표시
js/input.js             키보드 입력 (DAS / ARR)
js/settings.js          조작키·타이밍 설정과 저장
js/settings-ui.js       설정 창
js/progress.js          푼 문제 기록
js/puzzles.js           문제 정의
js/puzzle-session.js    판정과 되돌리기 (DOM 비의존)
js/menu.js              메인 화면
js/main.js              원본 페이지
js/puzzle-main.js       퍼즐 페이지
tests/engine.test.mjs   엔진 규칙
tests/puzzles.test.mjs  문제 풀이 가능성과 세션 동작
```

`js/engine.js` 와 `js/puzzle-session.js` 는 DOM을 전혀 건드리지 않습니다.
그래서 브라우저 없이 그대로 테스트할 수 있습니다.

## 테스트

```sh
node tests/engine.test.mjs
node tests/puzzles.test.mjs
```

엔진 쪽은 회전 항등성, 월킥, 벽 충돌, 라인 클리어, 점수와 백투백, 락 딜레이,
T-스핀 양성/음성 판정을 검사합니다.

퍼즐 쪽은 **모든 문제가 실제로 풀리는지**를 직접 확인합니다. 정답 좌표를
믿지 않고, 조각이 등장 위치에서 이동·회전(월킥 포함)·낙하로 **실제로 닿을 수
있는 자리**를 전부 탐색한 뒤 그 안에 정답이 있는지 봅니다. 닿을 수 없는 문제는
플레이어가 아니라 여기서 걸립니다.
